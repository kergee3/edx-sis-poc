# 学校受入に必要な最小限データ項目（入学・転入学）

児童生徒の**入学・転校（転入学）**時に、学校側が受け入れるために必要となる最小限のデータ項目を、政府の標準準拠システム仕様から整理したもの。本プロジェクト（行政/教育/名簿機能）の設計の基礎資料。

> 調査日: 2026-06-03 ／ 典拠: 就学事務システム（学齢簿編製等）標準仕様書【第4.0版】（文部科学省, 2026-01-08公開）。原典はリポジトリに複製せず、外部リンクを [docs/references/README.md](../references/README.md) の索引に記録する。
>
> 用語（英語表記）: 学習eポータル = Learning e-Portal ／ 校務支援システム = Student Information System (SIS。政府標準では School affairs support system / SSS) ／ 学習ツール = Learning tool

## 0. 前提：学齢簿と「学校が受け取る情報」の関係

- **学齢簿**は市区町村教育委員会が編製・管理する帳簿で、記載事項は**学校教育法施行規則第30条**で法定されている。就学事務システム（学齢簿編製等）はこの学齢簿を管理する自治体側システム。
- 学校（校長）が入学・転入学の受入時に教育委員会から直接受け取るのは、学齢簿そのものではなく**通知書**である:
  - 新入学 → **入学通知書**（小学校/中学校、学校教育法施行令第5条）
  - 転入学 → **転入学通知書**（学校教育法施行令第6条）／ **編入学通知書**（在外等からの編入）
  - 指定校変更・区域外就学 → 就学校変更許可通知書／区域外就学許可通知書 等
- したがって「学校が受け入れるのに必要な最小限のデータ項目」は、**通知書（帳票）に印字される項目**が中核となる。学齢簿の全データ項目はその供給源（マスタ）であり、参考として併記する。
- 学校内部の校務（指導要録・出欠・成績等）に必要な追加項目は、別途**統合型校務支援システム**側で管理され、就学事務システムとはクラス・出席番号・学籍番号等で連携する（§4）。

## 1. 学校が受け取る「通知書」の印字項目（＝受入に必要な最小限）

出典: 標準レイアウト及び標準印字項目【第4.0版】（`...-hyojun-layout-...pdf`）。すべて印字フォントは IPAmj明朝（IPAmjexMincho と同系）。

| # | 項目 | 内容 | 区分 |
| --- | --- | --- | --- |
| 1 | 児童生徒氏名（＋フリガナ） | 本人氏名（外国籍は外国人氏名）。振り仮名も出力 | 必須 |
| 2 | 生年月日 | 和暦／西暦。不詳の場合はその旨 | 必須 |
| 3 | 住所 | 児童生徒の現住所 | 必須 |
| 4 | 保護者氏名（＋フリガナ） | 共同親権時は両親権者を分割表示可 | 必須 |
| 5 | 転学期日 | 異動前の学校の転学年月日 | 必須 |
| 6 | 前就学校／（前就学校）学年 | 異動前の就学校名・学年 | 必須 |
| 7 | 転入期日 | 異動後の学校入学年月日 | 必須 |
| 8 | 転入学校／（転入学校）学年 | 異動後の就学校名・学年 | 必須 |
| 9 | 備考・特記事項 | 任意文言 | 任意 |

| # | 項目 | 内容 | 区分 |
| --- | --- | --- | --- |
| 1 | 児童（生徒）氏名（＋フリガナ） | 本人氏名 | 必須 |
| 2 | 生年月日 | 和暦／西暦 | 必須 |
| 3 | 住所 | 児童生徒の現住所 | 必須 |

| 6 | 入学期日 | 学校入学年月日 | 必須 |

> 名簿系で学校に渡る項目は「小学校/中学校入学者名簿」(帳票要件 4.2.6 / 4.3.14) も参照。性別・現住所・出身校・就学校変更/区域外就学事由などが付加される。

## 2. 受入に必要な最小限データ項目（分類・統合ビュー）

上記通知書の供給源である学齢簿データ（§3）と突き合わせ、学校受入の観点で最小限項目を分類したもの。

| 分類 | 最小限項目 | 法的根拠／出典 |
| --- | --- | --- |
| 本人 | 氏名、氏名フリガナ、生年月日、性別 | 施行規則30条1号（性別は名簿で付加） |
| 本人（外国籍） | 外国人氏名（英字・漢字）、通称名、国籍 | 機能要件 1.1.1 |
| 住所・連絡 | 現住所（郵便番号） | 施行規則30条1号 |
| 保護者 | 保護者氏名・フリガナ、児童生徒との関係（続柄） | 施行規則30条2号 |
| 保護者（補足） | 共同親権時の監護者／共同親権者情報 | 機能要件 1.1.2（令和6年民法改正対応） |
| 在籍・学校 | 就学校名、学年、学級区分（通常/特別支援） | 施行規則30条3号イ／機能要件 1.1.3 |
| 入学（新入学） | 入学校名、学校入学年月日 | 施行令5条／施行規則30条3号イ |
| 転入学 | 前就学校・学年、転学期日、転入学校・学年、転入期日 | 施行令6条／転入学通知書 |
| 指定校区 | 指定小学校区／指定中学校区、就学指定校名 | 機能要件 1.1.3（その他項目） |

凡例: 「必須」は標準仕様で実装必須機能または法定記載事項。区分や続柄等の補足は出典欄に明記。

## 4. 校務支援システム等との連携（補足）

- クラス・出席番号・学籍番号は就学事務システムでは標準オプション扱いだが、**統合型校務支援システムとの連携**・学齢簿の出力順に使われる（機能要件 1.1.3 備考）。学校が校務で実運用するにはこれらが加わる。
- システム間のデータ要件・連携要件は、デジタル庁「地方自治体の基幹業務システムの統一・標準化」の[データ要件・連携要件](https://www.digital.go.jp/policies/local_governments/specification/)でも横断的に管理される。
- 学齢簿情報の出力仕様は本体仕様書 第5章「5.4.2 就学事務システム（学齢簿編製等）からの出力」を参照。
- **DB 格納後の校務支援システム・学習eポータルでの持ち方**（OneRoster 連携・UUID 利用者識別子・氏名/文字集合の扱い）は、続編 [koumu-eportal-student-data-model.md](koumu-eportal-student-data-model.md) で整理。

## 5. 留意点

- 振り仮名（フリガナ）は令和の戸籍法改正（氏名の振り仮名法制化）に伴い管理・出力が必須化されている。
- 令和6年民法改正（離婚後共同親権）対応として、共同親権者・監護者情報の管理が第4.0版で追加された（保護者が複数になりうる）。
- 外国籍児童生徒は氏名（英字・漢字・通称名）の複数表記管理が必要で、文字数も住民記録に合わせる。印字に MJ特有文字を含む漢字が出るため、MJ（文字情報基盤）対応フォントが要件に組み込まれている（印字指定が IPAmj明朝）。MJ特有文字の定義は [koumu-eportal-student-data-model.md](koumu-eportal-student-data-model.md) §5.0 を参照。
